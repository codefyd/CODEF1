# «نقطة» — ريل كودف التعريفي

> الفكرة كلها في سطر واحد: **الخطّاط العربي يقيس حروفه بالنقطة، وكل مشروع يبدأ بنقطة.**
> الفيديو يبدأ بنقطة معيّنة (مربع مائل ٤٥°، نقطة الخط العربي) وينتهي بنفس النقطة في نفس المكان، فيدور البنر بلا خط فصل.

---

## ١. الثوابت التقنية

| البند | القيمة |
|---|---|
| المقاس الأساسي | 1080 × 1080 |
| نسخة البنر العريض | 1920 × 720 (نفس المشاهد، التخطيط يتكيّف تلقائيًا) |
| معدل الإطارات | 60 |
| المدة | 30.000 ثانية بالضبط = 1800 إطار |
| الإيقاع | 128 نبضة/دقيقة ← النبضة = 0.46875 ث ← **الفيديو كامل = 64 نبضة = 16 مقطعًا موسيقيًا** |
| مصدر الإطار | دالة `renderAt(t)` نقية: نفس الزمن = نفس الصورة، لا `Date.now` ولا `Math.random` بلا بذرة |
| الالتقاط | «Playwright» ← صور PNG ← «ffmpeg» |
| الصوت | «numpy» ← ملف WAV ← يُدمج مع الفيديو |

كل زمن في الكود يُكتب بالنبضات لا بالثواني:

```js
const BPM = 128, BEAT = 60 / BPM;          // 0.46875
const b = (n) => n * BEAT;                  // b(36) = 16.875s
```

| الدور | اللون | الاستخدام |

| الخلفية | `#0A0A0D` | حبر شبه أسود، مع حبيبات خفيفة |
| اللون الجريء الوحيد | `#C8FF2E` | ليموني كهربائي: الكلمات المهمة، النقطة، الومضات |
| الأبيض الدافئ | `#F2EDE3` | كل النصوص العادية |

**الخطوط** (موجودة في المسار أدناه):

```
assets/fonts/fonts.css
```

- عائلة «Fatimah» بوزن ٩٠٠ لكل العناوين الكبيرة، وبوزن ٤٠٠ أو ٥٠٠ للنصوص الصغيرة.
- عائلة «Fatimah Swash» هي نفس الخط لكن الذيول مفعّلة دائمًا. التبديل إليها في إطار الارتطام يجعل ذيل النون والياء والكاف والقاف والسين **ينمو** فجأة. هذا هو «تحريك الذيول».
- الخط لا يحتوي حروفًا لاتينية، فالنصوص اللاتينية (الموقع، الساعة في الزوايا) تحتاج خطًا لاتينيًا ثقيلًا مفتوح الترخيص يُحمَّل محليًا داخل مجلد الخطوط، مثل «Unbounded» أو «Archivo Black».

**ممنوعات:** لا شعارات، لا صور خارجية، لا إيموجي. أشكال هندسية فقط: معيّن (نقطة الخط)، دائرة، مربع، خط، قوس.

**الزوايا** (واجهة تقنية رفيعة ثابتة طول الفيديو):

- أعلى اليمين: `كودف ● REC`
- أعلى اليسار: عدّاد زمني بالأرقام العربية الهندية مثل `٠٠:١٦:٥٢`
- أسفل اليمين: رقم المشهد `مشهد ٣/٥`
- أسفل اليسار: `128 BPM` مع مؤشر ينبض مع كل نبضة

## ٣. الابتكارات الأربعة (هي التي تجعله مختلفًا)

### أ. محرّك الكشيدة، لا تمطيط الصورة

تمطيط الحروف العربية الحقيقي هو **الكشيدة** (حرف التطويل `U+0640`)، لا `scaleX`. المحرك يحسب عدد الكشيدات كرقم عشري:

```js
// k = 4.3  ← ارسم الكلمة بـ 4 كشيدات وبـ 5 كشيدات، وامزج بينهما بنسبة 0.3
// مع ضغط أفقي بسيط للنسخة الأطول حتى يتطابق العرض، فتبدو الحركة ناعمة لا متقطعة
function kashida(word, index, k) { /* ... */ }
```

الكشيدة تُضاف بعد الحرف الذي يقبل الوصل فقط (ليس بعد: ا د ذ ر ز و ة ء).

### ب. تتابع الحروف بدون كسر الوصل

تقسيم الكلمة العربية إلى حروف منفصلة يكسر أشكالها. الحل: كل حرف يُرسم وحده لكن محاطًا بحرف الوصل الصفري `U+200D` من الجانبين حسب موضعه، فيحتفظ بشكله الأوسط أو الأخير. ثم يُحرَّك كل حرف بتأخير متتابع **من اليمين إلى اليسار**.

### ج. النقطة الحلقية

أول إطار وآخر إطار متطابقان: معيّن ليموني صغير في وسط الشاشة. في النهاية، نقطة آخر الجملة تطير وتستقر مكانه. البنر يدور بلا قفزة.

### د. الصوت مولَّد من الحركة نفسها

الصوت لا يُركّب بعد الفيديو، بل يُقرأ من نفس جدول الأحداث. صوت الكشيدة نغمة تصعد طبقتها مع طول التمطيط. نقرة كل حرف مكتوب لها طبقة مختلفة قليلًا. لا ملفات صوتية جاهزة.

## ٤. السيناريو، نبضة بنبضة

### المشهد ١: النقطة تنفجر ← كودف (النبضات ٠ ← ٨ | 0.00 ← 3.75 ث)

1. نبضة ٠: معيّن ليموني واحد في المنتصف، يتنفس.
2. نبضة ٢: ينفجر إلى ١٢ شكلًا هندسيًا (معيّنات، دوائر، أقواس) بتسارع أُسّي، وصوت نفخة.
3. نبضة ٤: الأشكال ترتد وتتجمّع لتكوّن هيكل الكلمة، بتخفيف مطّاطي.
4. نبضة ٦: كلمة **كودف** تنبثق بوزن ٩٠٠ مع ارتطام واهتزاز، ونقطة الفاء هي المعيّن الأصلي نفسه عائدًا إلى مكانه.
5. تحتها صغيرًا وبلون أبيض دافئ: **تصميم وتطوير منتجات رقمية**

### المشهد ٢: الخطّاف (النبضات ٨ ← ١٤ | 3.75 ← 6.56 ث)

- السطر الأول يظهر حرفًا حرفًا: **من الفكرة**
- ثم تتمطط الكاف في «الفكرة» بالكشيدة حتى تكاد تلمس حافة الشاشة: **من الفكـــــــرة**
- في نبضة ١٢ ترتطم الكلمة الأخيرة من الأعلى بقوة مع اهتزاز وتبديل إلى خط الذيول: **إلى منتج.**
- الشرارة البرتقالية تظهر لأول مرة هنا، لحظة الارتطام فقط.

### المشهد ٣: محادثة الذكاء الاصطناعي (النبضات ١٤ ← ٣٣ | 6.56 ← 15.47 ث)

صندوق كتابة في أسفل الشاشة، مؤشر كتابة على **اليسار** (لأن النص من اليمين). كل طلب: يُكتب ← يظهر الكائن في الأعلى ويُبنى قطعة قطعة ← يُحذف النص حرفًا حرفًا بسرعة ← الطلب التالي. كل طلب ٤ نبضات.

| # | الطلب المكتوب | الكائن الذي يُبنى فوق | المشروع الحقيقي |
|---|---|---|---|
| ١ | ابنِ لي منصة تدير شاشات العرض | ثلاث شاشات هندسية تضيء بالتتابع | سماراتس |
| ٢ | أبغى نظام حجوزات ومالية بمسار واحد | تقويم شبكي تمتلئ خاناته | سلس |
| ٣ | لوحة تقيس الأداء التسويقي | أعمدة بيانية تصعد مع رقم يعدّ | نظام ولاء |
| ٤ | موقع أذكار يرافقني كل يوم | حلقة ٣٣ حبة تكتمل | أذكار كودف |

ثم **كلمة الرد الكبيرة** (النبضات ٣٠ ← ٣٣):

- **تم** بوزن ٩٠٠ في منتصف الشاشة.
- تتمطط التاء بالكشيدة: **تـــــــم**
- ترتطم مع تبديل الذيول (ذيل الميم ينمو)، اهتزاز قوي.
- **تنفجر** إلى جزيئات ليمونية وبرتقالية، مع صوت ارتطام منخفض.

### المشهد ٤: العدّ ثم الإيقاع (النبضات ٣٣ ← ٥٦ | 15.47 ← 26.25 ث)

**العدّ التنازلي** بالأرقام العربية الهندية، رقم في كل نبضة مع صوت نغمة، وصوت صاعد تحته:

```
نبضة 33 → ٣
نبضة 34 → ٢
نبضة 35 → ١
نبضة 36 → السقوط: يبدأ الإيقاع الكامل 16.875s
```

**بعد السقوط** كل قطع على نبضة، كل مقطع مدته محددة:

| النبضات | اللحظة | المحتوى |
|---|---|---|
| ٣٦ ← ٤٠ | صفوف نصية | أربعة صفوف تنزلق بعكس بعضها: **بوابات مؤسسية · أنظمة إدارية · لوحات متابعة · منصات تفاعلية** |
| ٤٠ ← ٤٢ | تحوّل | الصفوف تنضغط إلى كلمة واحدة: **عربي** ثم تتحول إلى **RTL** بمسح أفقي |
| ٤٢ ← ٤٤ | انفجار البلاطات | الشاشة تنقسم إلى شبكة ٦×٦ بلاطة تنقلب بالتتابع كموجة من اليمين |
| ٤٤ ← ٤٨ | المكعب ثلاثي الأبعاد | مكعب يدور ربع دورة كل نبضة، على أوجهه الأربعة: **أصمّم · أبرمج · أُطلق · أطوّر** |
| ٤٨ ← ٥٠ | اللزوجة | نقاط ليمونية تندمج وتنفصل بتأثير لزج ثم تكوّن معيّنًا |
| ٥٠ ← ٥٢ | الكلمة الممطوطة | **إبـــــــــداع** تتمطط بعرض الشاشة كاملًا ثم ترتد |
| ٥٢ ← ٥٤ | نفق السرعة | خطوط تندفع من المركز، والكاميرا تخترقها |
| ٥٤ ← ٥٦ | العدّادات | ثلاثة أرقام تعدّ بسرعة: **+١٠ مشاريع** · **١٠٠٪ عربي** · **∞ تفاصيل** |

### المشهد ٥: الختام (النبضات ٥٦ ← ٦٤ | 26.25 ← 30.00 ث)

- الإيقاع يتوقف فجأة. سكون.
- جملة الختام تُكتب حرفًا حرفًا مع نقرة لكل حرف: **مشروعك القادم يبدأ بنقطة**
- تظهر تحتها الحسابات بحجم أصغر:

```
codef8.com
واتساب ‎+966 56 284 8586
```

- النبضة ٦٢: نقطة آخر الجملة تتحول إلى معيّن ليموني، والنص كله يتلاشى بضبابية.
- النبضة ٦٤: المعيّن يستقر في منتصف الشاشة، **مطابقًا للإطار الأول**.

## ٥. قاموس الحركة

| الاسم | الاستخدام |
|---|---|
| تخفيف أُسّي `expoOut` | الانفجارات والانزلاقات |
| تخفيف راجع `backOut` | الظهور بارتداد (pop) |
| تخفيف مطّاطي `elasticOut` | تجمّع الأشكال، ارتداد الكشيدة |
| الارتطام | الحجم من 2.4 إلى 1 في 5 إطارات + اهتزاز يتلاشى في 12 إطارًا + ومضة بيضاء إطار واحد |
| التلاشي بضبابية | ضبابية من 0 إلى 24 بكسل مع شفافية إلى صفر |
| القطع على النبضة | كل تبديل مشهد في المشهد ٤ يقع على إطار النبضة تمامًا |
| المسح | قناع مائل ١٢° يعبر الشاشة في نبضة واحدة، من اليمين دائمًا |

## ٦. قاموس الصوت (كله مولَّد بـ numpy)

| الصوت | يُولَّد من |
|---|---|
| نفخة | ضجيج أبيض بمرشح يتحرك من منخفض إلى مرتفع |
| فرقعة | جيب قصير ينخفض ترددُه بسرعة |
| نقرة مفتاح | دفقة ضجيج ١٥ مللي ثانية، طبقتها تتغير قليلًا مع كل حرف |
| نغمة | جيب نقي قصير (للعدّ التنازلي والعدّادات) |
| ارتطام | جيب منخفض ٥٥ هرتز ينخفض + ضجيج مقصوص |
| صاعد | ضجيج بمرشح يصعد + نغمة تصعد، طوله ٣ نبضات قبل السقوط |
| الإيقاع | طبل منخفض على كل نبضة، تصفيق على ٢ و٤، صنج على الأنصاف |
| كشيدة | نغمة تصعد طبقتها بنسبة طول التمطيط |

الصوت يُقرأ من نفس جدول الأحداث الذي تقرأ منه الحركة، فيستحيل أن ينحرف التزامن.
